Fyodor Dostoevsky Fan site built with react and tailwind css

Utilizing the react router, the purpose of this site is to expose more people to the fascinating philosophy of Dostoevsky.

## 📖 About the Project

current status: work in progress. More features will be added soon.

This project is a fan website of the famous philosopher Fyodor Dostoevsky. I built it because I think his philosophy is very inspirational and even though at times its considered dark, I consider it uplifting. Its for fans of Dostoevsky who want to know a little bit more about him. It utilizes the react router, which helps update pages without having to refresh the page every single time.

## ✨ Features

-Click on documentary to watch a youtube documentary about Dostoevsky
-Features a home page, about page, books page, and a link to a youtube documentary.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- React
- React Router
- Git / GitHub
